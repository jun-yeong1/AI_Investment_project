다이어그램 · 흐름도

1. 첫 번째 다이어그램 (랜덤 포레스트 설명)
- Data → Tree 1, Tree 2, Tree n
- 각 Tree 내부에 빨간색과 파란색 노드가 있음, 빨간색 노드에서 화살표가 이어짐
- Tree 1, Tree 2, Tree n → Average → Prediction

설명: 
"A 'forest' of decision trees. Each individual tree is a weak predictor, but similar to the wisdom of crowds, their ensemble average forms a strong predictor."

2. 두 번째 다이어그램 (QLS 모델링 방법론)
- Data set → Training set → k fold CV → Best parameters
- Training set → Imputation → Train model
- Data set → Testing set → Imputation → Test model

설명:
"Modeling methodology adopted by QLS. Abbreviations: CV=cross-validation."
