# AI_Investment_project
## RAG (Retriever)

에이전트가 판단 기준 · 제도 · 통계를 찾는 참고 문서 검색. 사용법과 내부 구조는 [`rag/README.md`](rag/README.md).

| 항목 | 내용 |
|---|---|
| 문서 | 6종 134쪽 — 규제: FDA Expedited Programs / 기술: KISTEP 브리프, Jayatunga(2024), 생명공학연구원 이슈페이퍼 / 시장: BIO 임상 성공률, 기술특례상장 제도 개선 방안 |
| 텍스트화 | PyMuPDF 글자 추출 + 표 · 그래프 · 이미지 쪽은 비전 LLM(gpt-4.1-mini) 전사. 정보는 버리지 않고 편집 흔적(줄번호 · 쪽번호)만 정제 |
| 청킹 | **r500** — 문자 기준 500자, 겹침 50자 |
| 임베딩 | **BAAI/bge-m3** (오픈소스, 다국어, 입력 8,192토큰) |
| Vector DB | **FAISS** (로컬 파일, doc_type 필터로 에이전트별 문서 분리) |
| 검색 | 한 · 영 질문 → FAISS → LLM 관련성 채점 → 1회 재작성 (Agentic RAG) |
| 성능 | **Hit Rate@3 0.824 · MRR 0.703** (평가셋 34문항, 정답 = 문서 · 쪽) |

### 선택 근거 — 실험 (`python -m rag.experiment`)

청킹 5종 × 임베딩 3종 × 검색 3종을 같은 평가셋으로 비교했다. FAISS 검색의 MRR:

| 임베딩 \ 청킹 | r500 | r1000 | r1500 | page | struct |
|---|---|---|---|---|---|
| **bge-m3** | **0.703** | 0.657 | 0.631 | 0.692 | 0.696 |
| intfloat/multilingual-e5-large | 0.580 | 0.535 | 0.552 | 0.535 | 0.632 |
| jhgan/ko-sroberta-multitask | 0.425 | 0.398 | 0.413 | 0.418 | 0.454 |

- **임베딩**: bge-m3가 모든 청킹에서 1위. 문서 6종 중 3종이 영문이라 한국어 특화 모델(ko-sroberta)은 약하고, 입력 한도(ko-sroberta 128토큰, e5 512토큰)가 짧아 긴 청크가 잘린다. 리더보드 순위가 아니라 우리 문서 평가셋 결과로 골랐다.
- **청킹**: r500 · struct(문서 구조 기반) · page가 오차 범위(질문 2개 = MRR 0.059) 안에서 비슷하다. 규칙(MRR 최고, 오차 범위 안에서 20% 이상 빠르면 그쪽)에 따라 r500.
- **검색 방식**: FAISS 단독이 BM25(최고 0.609) · 앙상블보다 대체로 높아 FAISS를 쓴다. 전체 표는 [`data/eval/results.md`](data/eval/results.md).
- **설계서와 달라진 점**: 설계 단계의 가설(청크 1000자 · BM25+Dense 앙상블)을 실측 결과에 따라 r500 · FAISS로 바꿨다.

### 한계

- 평가셋 34문항은 LLM 초안을 코드로 검증한 것이라 사람 검수가 더 필요하다. 질문 수가 적어 1~2문항 차이는 오차다.
- 비전 전사는 틀릴 수 있다. 보고서에 인용하는 표 수치는 원문과 대조한다.
- 원본 PDF 6종은 모두 `data/raw/`에 들어 있다.
- 재현: `pip install -r requirements.txt` → `python -m rag.prepare` (비전 전사 캐시가 저장소에 있어 API 키 없이 준비된다).
